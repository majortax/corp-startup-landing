# 무료법인설립 파트너스 동행

메이저택스앤컨설팅의 무료법인설립 안내 페이지입니다. `index.html` 하나로 동작하는 정적 페이지예요.

## 상담 접수

- 현재 전화 문의는 메이저택스 고객센터 `02-554-5920`으로 연결합니다.
- 온라인 상담 폼은 문의 DB와 알림 연동이 준비된 뒤 추가합니다. 데모 성공 화면은 표시하지 않습니다.
- 무료 지원 여부와 범위, 별도 비용은 사업 상황을 확인한 뒤 안내합니다. 확정되지 않은 지원 금액·감면율·파트너 명단은 페이지에 게시하지 않습니다.

## 검토 배포

- 작업 브랜치의 Vercel 미리보기에서 페이지를 확인합니다.
- 공개 GitHub Pages와 Vercel 운영 페이지는 `main` 병합 후 갱신합니다.
- 미리보기에는 검색 제외 메타태그가 적용되어 있습니다.

## GitHub Pages

`main` 브랜치를 GitHub Pages로 배포하면 아래 주소에서 공개 페이지를 볼 수 있습니다.

```
https://<GitHub 계정명>.github.io/corp-startup-landing/
```

현재 GitHub Pages 배포는 저장소 Settings → Pages의 `main` / `/(root)` 설정을 사용합니다.
