# 법인설립파트너스 랜딩페이지

법인 설립 대행 서비스 랜딩페이지 시안입니다. `index.html` 하나로 동작하는 정적 페이지입니다.

## GitHub Pages로 미리보기

이 저장소를 GitHub Pages로 배포하면 아래와 같은 주소로 누구나 접속할 수 있습니다.

```
https://<GitHub 계정명>.github.io/corp-startup-landing/
```

배포 방법은 저장소의 Settings → Pages 메뉴에서 "Deploy from a branch"를 선택하고
브랜치를 `main`, 폴더를 `/(root)`로 지정하면 됩니다.
